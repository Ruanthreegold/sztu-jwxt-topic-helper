# 截图目录

README 引用了以下三张图，文件名要对上（放进本目录）：

| 文件名 | 内容 | 打码要求 |
|---|---|---|
| `panel.png` | 教务系统「学生选题」页右下角的助手面板 | 无特别要求 |
| `excel.png` | 导出的 Excel 打开效果（能看到列头和筛选） | **必须打码**：教师手机号、办公电话、同学姓名 |
| `install.png` | Tampermonkey 新建脚本 / 粘贴代码的界面 | 无特别要求 |

## 打码提醒

这些截图会**永久公开**在 GitHub 上（全网可搜），和发在校内论坛不是一回事：

- 教师在「办公电话」「手机号码」「联系方式」里的号码 —— 打码或直接裁掉列
- 「产业导师姓名」「合作单位名称」—— 涉及企业信息，建议打码
- 浏览器地址栏里的 `tid=` 那串参数 —— 可打码，虽然只是主键
- 个人头像、昵称、浏览器书签栏 —— 裁掉

用系统自带的「画图」/「截图工具」里的马赛克，或者粘贴到 PPT 上用半透明色块盖住即可。
